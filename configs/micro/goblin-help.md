# Goblin Keybinds 🔥

## Navigation
| Key | Action |
|-----|--------|
| `Ctrl+n` | Next split |
| `Alt+w` | Previous split |
| `Ctrl+w` | Next split → First split (wrap) |
| `Ctrl+b` | Open file in other pane |

## File Explorer (Ctrl+o)
| Key | Action |
|-----|--------|
| `Ctrl+o` | Toggle file tree |
| `↑/↓` | Navigate |
| `Enter` | Open file / Expand folder |
| `Space` | Toggle collapse folder |

## Tab Management
| Key | Action |
|-----|--------|
| `Ctrl+r` | Close rightmost tab |
| `Ctrl+l` | Close leftmost tab |

## Editing
| Key | Action |
|-----|--------|
| `Alt+/` | Toggle comment |
| `Ctrl+d` | Toggle comment |
| `Ctrl+s` | Save |
| `Ctrl+z` | Undo |
| `Ctrl+y` | Redo |
| `Ctrl+f` | Find |
| `Ctrl+c` | Copy |
| `Ctrl+x` | Cut |
| `Ctrl+v` | Paste |
| `Ctrl+a` | Select all |

## Commands
| Key | Action |
|-----|--------|
| `Ctrl+e` | Command bar |
| `Ctrl+P` | Palettero — fuzzy command palette |
| `F4` | Jump — quick file navigation |

## Plugin
| Key | Action |
|-----|--------|
| `F5` | Run plugin |
| `F9` | Run plugin (background) |
| `F12` | Make |

## Misc
| Key | Action |
|-----|--------|
| `Ctrl+q` | Quit micro |
| `Ctrl+h` | This help |
