# Delegate: task-organizer (plan.md)

## Trigger
Gunakan template ini ketika butuh **breakdown task** dari issue, PR, atau review feedback jadi milestones & sub-tasks.

## Template Hybrid

### Frame (wajib diisi)

```
Task: <judul task>
Input: <issue / PR / feedback text atau link>
Priority: <high / medium / low>
Scope: <besar / sedang / kecil — atau deskripsi scope>
```
## Tips Biar Output Maksimal
- **Input makin detail → breakdown makin akurat.** Kalo cuma "Bikin auth" doang, ya hasilnya bakal generic.
- **Sebutin file relevant** kalo ada — biar task-organizer bisa baca konteks project.
- **Kalo ada dependency dengan task lain**, tulis di freeform.
- **Jangan lupa template spawn kedua = kirim message aja** (session reuse).
