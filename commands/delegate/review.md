# Delegate: code-review (review.md)

## Trigger
Gunakan template ini ketika butuh **review code, PR, atau nyari bug/security issue**.

## Template Hybrid

### Frame (wajib diisi)

```
Target: <PR number / file path / commit>
Focus: <security / logic / quality / performance — centang yang perlu>
Level: <deep / quick>
```

## Tips Biar Review Tajam
- **Makin spesifik focus-nya, makin dalem review-nya.** Kalo checklist "semua" kadang jadi superfisial semua.
- **Kasi tau context kalo ada.** Misal: "Ini kode lama yang lagi direfactor" atau "Ini fitur baru, perlu security check ketat".
- **Kalo mau quick review** — cukup jelasin apa yang perlu dicek aja.
